## In v9 apps

- **UI folders**: each process task with a UI has a folder named after its task id, `App/ui/<taskId>/`. A new app has one task, `Task_1`, so its pages are in `App/ui/Task_1/layouts/` and their order is in `App/ui/Task_1/Settings.json`.
- **Headings**: use the `Heading` component. `Header` does not exist in v9.
- **Computed values**: a class that implements `IDataWriteProcessor`, registered in `RegisterCustomAppServices()`:

  ```csharp
  services.AddTransient<IDataWriteProcessor, MyDataWriteProcessor>();
  ```
