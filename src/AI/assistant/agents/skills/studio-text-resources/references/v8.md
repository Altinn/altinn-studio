## In v8 apps

- **Language selector.** Set `"showLanguageSelector": true` inside `pages` in a layout set's `Settings.json`, such as
  `App/ui/form/Settings.json`. To show it in every layout set, set it in `uiSettings` in `App/ui/layout-sets.json`
  instead. A value in a layout set's `pages` overrides `uiSettings`.

  ```json
  {
    "pages": {
      "order": ["Side1"],
      "showLanguageSelector": true
    }
  }
  ```

- **`dataModel.default`** is the `dataType` of the layout set in `App/ui/layout-sets.json`.
- **`applicationSettings`.** The app sends the `FrontEndSettings` keys to the frontend with the first letter in lower
  case. A setting written `HomeBaseUrl` in `appsettings.json` is `homeBaseUrl` in a variable's `key`.
