## In v9 apps

- **Language selector.** Set `"showLanguageSelector": true` in `App/ui/Settings.json`. That file holds the settings
  for every task, as a flat object with no `pages` property. Create it if it does not exist:

  ```json
  { "showLanguageSelector": true }
  ```

  To override the setting for one task, set `showLanguageSelector` inside `pages` in that task's
  `App/ui/<task id>/Settings.json`.
- **`dataModel.default`** is the `defaultDataType` in the task's `App/ui/<task id>/Settings.json`.
- **`applicationSettings`.** The frontend gets the `FrontEndSettings` keys exactly as `appsettings.json` writes them.
  Use the same spelling and case in a variable's `key`. The docs' example, `HomeBaseUrl` in the settings and
  `homeBaseUrl` in the variable, works only in v8.
