## In v9 apps

- **Language selector.** Set `"showLanguageSelector": true` at the top level of `App/ui/Settings.json`, not inside
  `pages`, and create the file if it does not exist.
  [Oversettelse](https://docs.altinn.studio/nb/altinn-studio/v9/develop-a-service/look-and-feel/tekster/oversettelse/)
  shows the file and how one task overrides the setting.
- **`dataModel.default`** is the `defaultDataType` in the task's `App/ui/<task id>/Settings.json`.
- **`applicationSettings`.** The frontend gets the `FrontEndSettings` keys exactly as `appsettings.json` writes them.
  Use the same spelling and case in a variable's `key`. The docs' example, `HomeBaseUrl` in the settings and
  `homeBaseUrl` in the variable, works only in v8.
