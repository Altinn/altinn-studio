# App configuration in v8 apps

## applicationmetadata.json

- Keep the `$schema` the file has, normally
  `https://altinncdn.no/toolkits/altinn-app-frontend/4/schemas/json/application/application-metadata.schema.v1.json`.
- The v8 schema knows only the old spelling `allowedContributers`, so an editor flags `allowedContributors`. The app
  reads both.
- A stateless `onEntry.show` is the `id` of a layout set in `App/ui/layout-sets.json`. The layout set's `dataType`
  is the stateless data type. Set `allowAnonymousOnStateless` on that data type.
- `enablePdfCreation` on a data type controls the PDF that v8 makes at the end of a task without a PDF service task.
  The `studio-process` skill covers it.
- The `eFormidling` block configures the legacy eFormidling shipment. The `studio-integrations` skill covers it.
- Nothing checks the file when the app builds. A duplicate `id` in `presentationFields` or `dataFields`, or a
  `dataTypeId` that no data type has, fails only when the app runs.

## appsettings*.json

- These `AppSettings` switches are off unless the app turns them on: `RemoveHiddenData`, `RequiredValidation`,
  `ExpressionValidation` and `EnforceDataTypeTaskId`. The template sets none of them. While a switch is off, the
  server skips that step: data in hidden components stays, and only the browser checks required fields and
  expression validations.
- `AppSettings` also has folder and file name keys, such as `ConfigurationFolder` and `ProcessFileName`. Leave them
  out.
- `FeatureManagement` goes through `Microsoft.FeatureManagement`, so a flag can also use feature filters.

## Secrets

- `ISecretsClient` has `GetSecretAsync(name)`.
- Locally, `ISecretsClient` looks for the secret in `secrets.json` in the folder the app runs from, normally `App/`,
  and then in the app's configuration, such as .NET user secrets. `secrets.json` is a flat object from secret name to
  value. Keep the file out of the repository.

## Autosave and file scanning

- `autoSaveBehavior` goes in `uiSettings` in `App/ui/layout-sets.json` for all layout sets, or in `pages` in a layout
  set's `Settings.json`.
- The file scan messages use the text keys `DataElementFileInfected` and `DataElementFileScanPending`. Without them,
  the app shows the key.

## Docs

Two v8 pages are outdated:

- The page on application metadata under `v8/repos/structure/` shows a format the app no longer reads, with `forms`
  and `shouldSign`. Do not follow it.
- [Events](https://docs.altinn.studio/nb/altinn-studio/v8/reference/configuration/events/) shows `IEvents` and
  `InstantiationHandler.cs`, which v8 no longer has. Only the part on `RegisterEventsWithEventsComponent` is current.

Pages for each setting:

- [Oppstart](https://docs.altinn.studio/nb/altinn-studio/v8/reference/configuration/startup/): `onEntry` and
  `instanceSelection`.
- [Aktørtyper](https://docs.altinn.studio/nb/altinn-studio/v8/reference/configuration/partytype/): `partyTypesAllowed`.
- [Stateless](https://docs.altinn.studio/nb/altinn-studio/v8/reference/configuration/stateless/): stateless apps and
  anonymous access. The section on starting an instance names `InstantiationHandler.cs`. Implement
  `IInstantiationProcessor` instead.
- [Meldingsboks](https://docs.altinn.studio/nb/altinn-studio/v8/reference/configuration/messagebox/): hiding
  instances, presentation fields and copying.
- [Hjelpefelter](https://docs.altinn.studio/nb/altinn-studio/v8/reference/configuration/shadowfields/),
  [Filskanning](https://docs.altinn.studio/nb/altinn-studio/v8/reference/configuration/filescan/) and
  [Autolagring](https://docs.altinn.studio/nb/altinn-studio/v8/reference/configuration/autosavebehavior/).
- [Automatisk sletting](https://docs.altinn.studio/nb/altinn-studio/v8/reference/configuration/process/auto-delete/):
  `autoDeleteOnProcessEnd`.
- [Spørringsparametere](https://docs.altinn.studio/nb/altinn-studio/v8/reference/configuration/queryparameters/):
  `returnUrl`. The page says the host must be the app's own. The app accepts any host in the environment's domain,
  such as `tt02.altinn.no`.
- [Innstillinger](https://docs.altinn.studio/nb/altinn-studio/v8/reference/configuration/settings/) and
  [Hemmeligheter](https://docs.altinn.studio/nb/altinn-studio/v8/reference/configuration/secrets/): `appsettings` and
  Key Vault.
