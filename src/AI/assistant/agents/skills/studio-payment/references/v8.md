# Payment in v8 apps

- `IOrderDetailsCalculator` has this method:

  ```csharp
  Task<OrderDetails> CalculateOrderDetails(Instance instance, string? language);
  ```

- Nothing checks the payment configuration when the app starts. The app checks it when an instance enters the payment
  task, and a mistake fails that `process/next`: `paymentConfig` or one of its IDs is missing, or, in Development, the
  payment data type is missing or not app-owned. Move an instance into the payment task to test the configuration.
- A `process/next` that leaves the task before the payment is paid fails with "The payment is not completed".
- The payment task's pages are a layout set: an entry in `App/ui/layout-sets.json` whose `tasks` lists the payment
  task's ID, and the folder `App/ui/<layout set id>/`. Its `Settings.json` can hold `pdfLayoutName`. The
  `studio-layouts` skill covers layout sets.
- [Setting up the payment pages](https://docs.altinn.studio/nb/altinn-studio/v8/guides/development/payment/backend-manual/configure-layouts/)
  shows how `PaymentDetails` refetches the order when a data model path among the keys of its `mapping` changes.
- The process moves on by itself when Nets reports the payment only in `Altinn.App` 8.12.0 or newer. The app then
  needs a Maskinporten client with the service owner scopes. The `studio-integrations` skill covers Maskinporten. In
  older apps, the frontend runs `confirm` when the user comes back to a paid payment task.

## Docs

- [The payment guide](https://docs.altinn.studio/nb/altinn-studio/v8/guides/development/payment/): the order of the
  steps, the service owner's grants, and how the process moves on when Nets reports the payment. The pages below
  hold the steps.
- [Calculating the payment](https://docs.altinn.studio/nb/altinn-studio/v8/guides/development/payment/backend-manual/calculate-payment/):
  `IOrderDetailsCalculator` with an example.
- [Setting up the payment pages](https://docs.altinn.studio/nb/altinn-studio/v8/guides/development/payment/backend-manual/configure-layouts/):
  the payment page, `PaymentDetails` and a receipt page.
- [Connecting to Nets Easy](https://docs.altinn.studio/nb/altinn-studio/v8/guides/development/payment/backend-manual/configure-secrets/):
  `NetsPaymentSettings` with the optional settings, the secret key in Key Vault and user secrets.
- [Secrets](https://docs.altinn.studio/nb/altinn-studio/v8/reference/configuration/secrets/): how to load Azure Key
  Vault as a configuration source and test with user secrets.
- [The payment concept](https://docs.altinn.studio/nb/altinn-studio/v8/concepts/payment/): how a payment flows, and that
  the service owner must keep the payment information as the Norwegian Bookkeeping Act requires.
