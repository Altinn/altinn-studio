# Expressions in a v8 app

## Functions v8 lacks

v8 has no `formatNumber`, in the frontend or the backend.

The v8 frontend has no `list`, `object`, `jmespath`, `sum`, `average` or `count`. The v8 backend has them from these
versions of `Altinn.App.Api`:

- `list`, `object` and `jmespath`: 8.12.4
- `sum` and `average`: 8.12.7
- `count`: 8.12.8

Use them only in gateway conditions, which only the backend evaluates in a v8 app, and only when the app's version
has them. The
[v8 expressions page](https://docs.altinn.studio/nb/altinn-studio/v8/reference/logic/expressions/) lists the
functions the v8 frontend has.

## Settings for `frontendSettings`

The v8 app sends the `FrontEndSettings` keys to the frontend with the first letter in lower case, but the backend
looks them up as `appsettings.json` writes them. A setting named `HomeBaseUrl` is `homeBaseUrl` in the browser, so
`["frontendSettings", "HomeBaseUrl"]` gives `null` in the frontend and the value in the backend. Name settings with a
lower-case first letter, and both agree.

`dataModel` and `component` return `null` in the frontend when the path points to an object or a list.

## The backend evaluates only what the app turns on

In v8, the backend evaluates `hidden`, `required` and the validation files only when the app turns on
`RemoveHiddenData`, `RequiredValidation` or `ExpressionValidation`. All three are off by default. The
`studio-validation` skill says what each one checks and when to turn it on. Before you turn one on, check that every
expression the backend then evaluates uses only backend functions and works without errors.

## RuleHandler.js and RuleConfiguration.json

The v8 frontend still runs `App/ui/<layoutSetId>/RuleHandler.js` with `RuleConfiguration.json` in the same folder.
They hold JavaScript rules for showing, hiding and computing that only the browser runs. New apps do not have them.
Write new logic as expressions or in C#. When an app has these files, leave the existing rules alone unless the task
is to replace them.

## Files

- Layouts are in `App/ui/<layoutSetId>/layouts/<page>.json`. The `studio-layouts` skill covers layout sets.
- Layout files use the schema
  `https://altinncdn.no/toolkits/altinn-app-frontend/4/schemas/json/layout/layout.schema.v1.json`.
