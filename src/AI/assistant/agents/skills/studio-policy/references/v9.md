# Policy in v9 apps

## The service owner's rights

The v9 workflow engine moves the instance as the service owner, not as the user. Storage checks those calls
against this policy, with `urn:altinn:org` as the subject. In a rule that is not scoped to a task, the policy must
give the service owner (`urn:altinn:org` = `[org]`):

- `read` and `write`, always
- `complete`, when the process has an `eFormidling` or `fiksArkiv` service task
- `delete`, when `autoDeleteOnProcessEnd` is `true` in `applicationmetadata.json`

For the workflow engine, the service owner needs no action for a task type, such as `confirm` or `reject`. Storage
always lets the service owner save a process transition. A payment task is the exception, in both versions: see
`SKILL.md`.

The template's service owner rule gives `read`, `write`, `instantiate` and `complete`. Keep it when you change other
rules.

## Build checks

Building the app checks the service owner's rights:

- [ALTINNAPP0800](https://docs.altinn.studio/nb/altinn-studio/v9/develop-a-service/reference/analysis/rules/altinnapp0800/)
  is an error: the policy does not give the service owner a right from the list above.
- [ALTINNAPP0801](https://docs.altinn.studio/nb/altinn-studio/v9/develop-a-service/reference/analysis/rules/altinnapp0801/)
  is a warning: the build cannot tell. A right given only in a rule scoped to a task causes it, and so does a Deny
  rule or a condition. Give the rights in a rule without a task.

## Service tasks

The process stops on each service task while the workflow engine runs it. While the instance is there, the app
checks users against the service task's ID:

- `read` to see the instance
- `write` to retry the task when it fails

Every service task accepts `write`, built-in or defined by the app. A user rule scoped to the task before a service
task does not cover the service task. Name the service task in the rule as well, or use a rule without a task.

## Before you finish

Build the app, and check that it reports neither ALTINNAPP0800 nor ALTINNAPP0801.

- [Definere autorisasjonspolicy](https://docs.altinn.studio/nb/altinn-studio/v9/develop-a-service/reference/configuration/authorization/):
