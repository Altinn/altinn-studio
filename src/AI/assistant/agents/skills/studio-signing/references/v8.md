# Signing in v8 apps

- The setup in this skill needs `Altinn.App` 8.6.0 or newer. SigneeList, SigningActions and SigningDocumentList call
  the `GET .../signing` endpoints, which 8.6.0 added, and user-controlled signing came in the same version.
- Nothing checks the signing configuration when the app starts. The app checks it when an instance enters the
  signing task, and a mistake fails that `process/next`:
  - `signatureConfig` or `signatureDataType` is missing
  - only one of `signeeProviderId` and `signeeStatesDataTypeId` is set
  - no registered `ISigneeProvider` has the `signeeProviderId`, or more than one has
  - in Development, the signature or signee-states data type is missing or not app-owned

  Move an instance into every signing task to test the configuration.
- In user-controlled signing, a missing `correspondenceResource` does not stop the task. The app logs an error, the
  signees get no message, and SigneeList shows their notification as failed.
- The app finds the signees, delegates, notifies, and revokes the rights inside the `process/next` request that
  enters or leaves the task.
- The signing task's pages are a layout set: an entry in `App/ui/layout-sets.json` whose `tasks` lists the signing
  task's ID, with its `dataType`, and the folder `App/ui/<layout set id>/`. The `studio-layouts` skill covers layout
  sets.
- `ref-data-as-pdf` comes from a `pdf` service task before the signing task, or from `enablePdfCreation` on the data
  task's form data type. Use one of them. With both, the instance gets two PDFs. The `studio-process` skill covers PDF
  tasks.
- The app uses the Maskinporten client you configure for it. User-controlled signing needs the Correspondence and
  service owner scopes that the
  [user-controlled signing guide](https://docs.altinn.studio/nb/altinn-studio/v8/guides/development/signing/runtime-delegated-signing/)
  lists. The `studio-integrations` skill covers Maskinporten.
- [Sign and submit](https://docs.altinn.studio/nb/altinn-studio/v8/guides/development/signing/sign-and-submit/) and
  [role-based signing](https://docs.altinn.studio/nb/altinn-studio/v8/guides/development/signing/role-based-signing/)
  have their own v8 guides. The role-based guide names a component `SigningStatusPanel`. No such component exists. Use
  `SigningActions`.
