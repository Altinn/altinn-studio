# Code lists in v8 apps

## Altinn.Codelists

Use version 8.0.3, the last 8.x release:

```xml
<PackageReference Include="Altinn.Codelists" Version="8.0.3" />
```

Always write this version, not the newest release. The newest will be a 9.x release once one is out, and
Altinn.Codelists 9 needs `Altinn.App.Core` 9 and does not work in a v8 app.

## Library code lists

The `lib**{org}**{codeListId}**{version}` form needs `Altinn.App.Api` 8.10.0 or later. An older app treats the value
as an ordinary `optionsId` and answers 404. Raise `Altinn.App.Api` and `Altinn.App.Core` together to a newer 8.x
version to use it.

## Code list providers

The methods end in `Async`: `IAppOptionsProvider.GetAppOptionsAsync` and
`IInstanceAppOptionsProvider.GetInstanceAppOptionsAsync`.

## The options folder

The app reads options files from the folder in the `OptionsFolder` app setting, which is `options/` by default. Keep
the default, since Studio reads and writes `App/options/`.

## Docs

- [Kodeliste fra organisasjonsbibliotek](https://docs.altinn.studio/nb/altinn-studio/v8/guides/development/options/sources/organisation-library/):
  the `lib**` reference with a pinned or the latest version.
- [Kodelister fra repeterede strukturer](https://docs.altinn.studio/nb/altinn-studio/v8/guides/development/options/sources/from-data-model/):
  `source` with its paths and labels.
- [Kodelister og svaralternativer](https://docs.altinn.studio/nb/altinn-studio/v8/guides/development/options/): every
  source, with filtering, sorting, preselection and what is saved in the data model.
- [Felles standard kodelister](https://docs.altinn.studio/nb/altinn-studio/v8/guides/development/options/sources/shared/): the IDs in
  Altinn.Codelists, and the methods that register one source or one SSB classification. Its example pins an older
  version of the package. Use the version above.
- [Dynamiske kodelister](https://docs.altinn.studio/nb/altinn-studio/v8/guides/development/options/sources/dynamic/):
  code list providers, query parameters and secure options. `mapping` on a selection component is deprecated, and v9
  removes it. Use `queryParameters` with a `dataModel` expression instead.
