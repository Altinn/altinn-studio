## In v9 apps

- **A task's default data model** is `defaultDataType` in the task's `App/ui/<task id>/Settings.json`. Bindings,
  text variables and expressions without a data type id read this model. When you connect a model to a task by hand,
  set both the data type's `taskId` and `defaultDataType`. Studio's process editor sets both.

  ```json
  {
    "pages": { "order": ["Side1"] },
    "defaultDataType": "soknad"
  }
  ```

- Without `defaultDataType`, the app backend falls back to the first data type in `applicationmetadata.json` that
  has a `classRef`, which can belong to another task. Always set it.
