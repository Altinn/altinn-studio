## In v8 apps

- **A task's default data model** is the `dataType` of the layout set in `App/ui/layout-sets.json` whose `tasks`
  lists the task. Bindings, text variables and expressions without a data type id read this model. When you connect
  a model to a task by hand, set both the data type's `taskId` and the layout set's `dataType`. Studio's process
  editor sets both.

  ```json
  {
    "sets": [{ "id": "form", "dataType": "soknad", "tasks": ["Task_1"] }]
  }
  ```

- Studio adds a new data type with `"enablePdfCreation": false`. Do the same when you add one yourself, or the app
  makes a PDF of the data at the end of the task. The `studio-process` skill covers PDFs.
