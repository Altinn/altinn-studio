## In v8 apps

- **Carry stateless values into the instance** with `mapping` on the `InstantiationButton` in the stateless form.
  Each entry is `"<field in the stateless data model>": "<field in the instance's data model>"`. The button reads
  from the default data model of the stateless layout set, and sends the values as prefill when it creates the
  instance. The app writes them into the data models it creates at the first task, before `prefill.json`.

  ```json
  {
    "id": "start",
    "type": "InstantiationButton",
    "textResourceBindings": { "title": "start.button" },
    "mapping": { "stilling": "soker.stilling" }
  }
  ```

## Docs

- [Konfigurasjonsfil](https://docs.altinn.studio/nb/altinn-studio/v8/guides/development/prefill/config/): how to
  write `prefill.json` in a v8 app.
- [Spørringsparametere](https://docs.altinn.studio/nb/altinn-studio/v8/guides/development/prefill/query-params/):
  the query parameter setup and its security caveats. Its validator example does not compile.
  `PrefillFromQueryParamsIsValid` returns a `Task<ValidationIssue?>`, `null` when the values are valid. When it
  returns an issue, the app answers 400 and does not use the values.
- [HTTP POST](https://docs.altinn.studio/nb/altinn-studio/v8/guides/development/prefill/instantiation/): form data
  sent in the instantiation request.
- [Egendefinert kode](https://docs.altinn.studio/nb/altinn-studio/v8/guides/development/prefill/custom/): prefill in
  `IInstantiationProcessor`. Follow the v7 code on the page, which v8 uses too.
- [Forhåndsutfylling, referanse](https://docs.altinn.studio/nb/altinn-studio/v8/reference/data/prefill/): every field in
  each source.
