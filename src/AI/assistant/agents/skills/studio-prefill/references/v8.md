## In v8 apps

- **Carry stateless values into the instance** with `mapping` on the `InstantiationButton` in the stateless form.
  Each entry is `"<field in the stateless data model>": "<field in the instance's data model>"`. The button reads
  from the default data model of the stateless layout set, and sends the values as prefill when it creates the
  instance. The app writes them into the data models it creates at the first task, before `prefill.json`.

  ```json
  {
    "id": "start",
    "type": "InstantiationButton",
    "textResourceBindings": { "title": "start.button" },
    "mapping": { "stilling": "soker.stilling" }
  }
  ```
