The request asks for help with developing this Altinn app or with Altinn Studio: building or changing the app (layouts, components, fields, data model, texts, expressions, validation, process, policy, deployment, integrations), a question about how Altinn Studio, Altinn apps or the services an app uses work (such as ID-porten, Maskinporten, the registers or access packages), or a general programming question in any language, such as about C#, JavaScript, SQL or regular expressions, since a developer can add custom code to the app. A request to build something stays relevant when its example content names an unrelated topic, such as a field about travel or a health form. A short reply that only makes sense as an answer to the assistant, such as "ja", "ok", "fiks det", "gjør det", "fortsett" or "og på side 2?", is relevant, also when no earlier turns are shown. So is an unclear request about the app: the assistant asks what the user means. A request for advice, facts or content about another topic itself (travel, health, law, finance, recipes, government and public administration in general, IT support, creative writing, lookups) is not relevant, even when it shares a word with an Altinn feature.
