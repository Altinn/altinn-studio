# Rules for agent docs

- Use short explanations in ASD-STE100 Simplified Technical English.
- A diagram has a preferred maximum of five elements. Split a larger diagram into two.
- Each module page starts with the code paths that it describes. When you change that code, examine the page.
- Do not write numbers that change often, such as item counts. Refer to the command or file that gives the current value.
- It is important that these docs does not become too verbose. When you make changes, they should be succinct.
