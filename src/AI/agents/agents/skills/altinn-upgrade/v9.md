## In v9 apps: TODOs after a completed upgrade

The upgrade is committed. In turn 2:

1. Run `upgrade_app_to_v9`. On a v9 app it runs again, applies the fixes of newer versions of the upgrade, and reports the TODOs again. It reads the C# without a build, so it can report a usage that is not real. Check each TODO in the code.
2. Read the files, and fix the TODOs that you offered.
3. Run `verify_changes`. It builds the app.
4. Commit, and list the fixed and the remaining TODOs in the body of the commit message.
