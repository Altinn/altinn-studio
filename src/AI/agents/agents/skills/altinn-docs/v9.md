## In v9 apps

docs.altinn.studio has no pages for v9 apps yet. The v8 pages in the index still describe the features that did not change. On these topics they are wrong for a v9 app, so follow the system prompt and the other skills instead:

- **Layout sets**: v9 has one UI folder per process task, `App/ui/<taskId>/`, and no `layout-sets.json`.
- **Dynamics**: `RuleConfiguration.json` and `RuleHandler.js` are gone. Use `hidden` expressions, and a C# `IDataWriteProcessor` for computed values.
- **Frontend page**: `App/views/Home/Index.cshtml` is gone. Extra scripts and styles go in `App/config/assets.json`, or in `App/wwwroot/custom-js` and `App/wwwroot/custom-css`.
- **PDF and eFormidling**: service tasks in `App/config/process/process.bpmn`, not settings in `applicationmetadata.json`.
- **Components**: `Heading` replaces `Header`, and `FileUpload` replaces `FileUploadWithTag`. `altinn_layout_props` gives the v9 properties of each component.
- **Datepicker**: `timeStamp` defaults to `false`, and `format` uses `dd.MM.yyyy`.
- **Authorization**: the service owner needs `read`, `write` and `complete`. See `skill(altinn-policy)`.
