# AGENTS.md

An interactive, keyboard-driven pitch deck (Vite + React + TypeScript, Norwegian text) that makes the
case for the v9 workflow-engine upgrade to a town-hall audience.

This directory lives on the parking branch `docs/v9-pitch-deck` **only**. It is parked here for team
review and is **never to be merged into `main`** — do not rebase it onto other work, and do not treat
it as part of the product build.

Run it with `npm ci && npm run build && npm run preview`, then open <http://localhost:4173> and press
`f`. `README.md` documents the deck engine, `NOTES.md` is the presenter run sheet, and `CONTENT.md` is
the fact sheet every claim in the deck traces back to.
