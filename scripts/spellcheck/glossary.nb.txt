# Bokmål glossary: Norwegian words the nb spell check accepts although the
# dictionary and Norsk Ordbank reject them. Language-neutral tokens (names,
# identifiers, formats) live in glossary.shared.txt instead. One word per
# line; '#' starts a comment; matching is case-insensitive.
#
# The dictionary is full-form (inflections are separate entries), so an
# accepted term's other forms need their own lines — add them as the check
# reports them. Keep entries alphabetized within each section (Norwegian
# collation: æ, ø, å sort last).
#
# Glossary or suppression? One rule: a CORRECT word the checker doesn't
# know belongs here; a WRONG spelling that cannot change belongs in
# suppressions.txt, scoped. A misspelling "fixed" by a glossary entry stays
# wrong in the product, so prefer fixing the text. Reviewing this file in a
# PR IS the native-speaker check: every line claims the word is correct
# bokmål used deliberately — remove a line to re-flag it everywhere. An
# entry that no longer rescues any flagged word is reported as stale by the
# check itself.
