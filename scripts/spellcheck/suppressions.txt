# Suppressions for the code (en-US) pass: WRONG spellings this repository
# must accept anyway — someone else's API, a wire contract — each scoped to
# where it is load-bearing. A CORRECT word the checker doesn't know belongs
# in a glossary instead (glossary.shared/nb/nn.txt). Norwegian in code that
# the classifier cannot see (identifiers, JSX text nodes) is also suppressed
# here, path-scoped, though extracting the copy to a language file is the
# better fix.
#
# Format: '#' comments and blank lines are free. A section is one or more
# @directives followed by one token per line (the exact word typos
# reports). A directive after a token starts a new section; nothing is
# inherited. Every section needs exactly one scope — say WHY in a comment
# next to the section or token:
#
#   @paths glob glob …         tokens allowed anywhere in matching files
#   @identifiers Name Name …   tokens allowed only as/inside these exact
#                              identifiers (narrow with @paths if needed)
#   @identifier-part           tokens allowed inside any LONGER identifier
#                              within @paths; the bare word stays enforced
#
# Scope is the point: typos' own allowlists are repo-wide, so a bare
# `organisation` entry would license the word in every ADR and comment. A
# token here is still reported OUTSIDE its scope, and an entry that matches
# nothing is reported as stale — the registry cannot quietly rot.
