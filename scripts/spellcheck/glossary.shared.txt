# both bokmål and nynorsk — names, quoted identifiers, formats and literals.
# Norwegian *words* never belong here; they go in glossary.nb.txt /
# glossary.nn.txt so a native reviewer of one language never has to rule on
# the other. One word per line; '#' starts a comment; matching is
# case-insensitive.
#
# Entries must earn their keep: the check reports an entry that no longer
# rescues any flagged word as stale, in either language. Reviewing this file
# in a PR is a name-spotting exercise, not a language ruling.
